# Student Performance Prediction using Machine Learning

## 📌 Project Overview

This project predicts whether a student will Pass or Fail based on Study Hours and Attendance using Machine Learning.

## 🎯 Business Problem

The objective is to predict a student's academic result using two important features:

- Study Hours
- Attendance

## 📊 Dataset

The dataset contains 8 student records with the following columns:

| Column | Description |
|---|---|
| Hours | Study hours |
| Attendance | Attendance percentage |
| Result | 0 = Fail, 1 = Pass |

## 🛠️ Technologies Used

- Python

## 🔎 Data Analysis

The project includes:

- Dataset understanding

- Statistical analysis

## 🤖 Machine Learning

A Logistic Regression model was used to predict the student's result.
